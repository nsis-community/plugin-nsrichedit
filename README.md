## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-nsrichedit/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `nsRichEdit.dll` to `Plugins/<variant>/`.
